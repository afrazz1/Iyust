# Object Notes

Интерактивная галерея 3D-моделей на Three.js. Модель можно вращать, масштабировать, переключать через список и приближать к отмеченным деталям кликом по аннотации.

## Локальный запуск

Проект не требует сборки. В Windows откройте **start.cmd** в папке проекта: локальный сервер запустится, а галерея откроется в браузере по адресу **http://localhost:8080**. Требуется установленный Node.js. Оставьте окно сервера открытым на время работы; Ctrl+C останавливает сервер.

Можно запустить сервер вручную командой `node server.cjs` или, если установлен Python, `python -m http.server 8080 --bind 127.0.0.1` из папки проекта, затем открыть **http://localhost:8080**.

Открытие `index.html` напрямую через `file://` не поддерживается: браузер блокирует загрузку модулей и моделей. Для загрузки Three.js с CDN требуется интернет. Используйте один и тот же адрес **http://localhost:8080**, чтобы видеть ранее сохранённые в браузере точки.

## Аннотации и экскурсия

- Сайт всегда открывается в режиме просмотра: клик по точке показывает название и описание, элементы изменения точек скрыты.
- Для входа нажмите маленькую кнопку **Редактор точек** в правом нижнем углу и введите код **экспозиция-команда**. Код задаётся константой `EDITOR_ACCESS_CODE` в `annotations.js`. Это защита от случайных действий, а не серверная авторизация: код доступен в исходниках сайта. После выхода из редактора, начала экскурсии, смены модели или перезагрузки для редактирования снова нужен код.
- В редакторе кликните по поверхности модели. Введите название и описание и нажмите **Сохранить**. Вращение модели перетаскиванием не добавляет точку.
- В редакторе нажмите на существующую точку, чтобы изменить текст или удалить её.
- Точки и ракурсы новых точек сохраняются автоматически в `localStorage` отдельно для каждой модели. После перезагрузки они восстанавливаются. Данные доступны только в том же браузере и на том же адресе сайта; очистка данных сайта удаляет их. Общего серверного хранилища нет.
- **Скачать точки** сохраняет JSON-файл текущей модели: названия, описания, координаты, ракурсы камеры и порядок экскурсии. Храните файл как резервную копию или перенесите на другое устройство.
- **Загрузить точки** восстанавливает такой файл для выбранной модели. После проверки файла и подтверждения текущие точки заменяются, сразу отображаются на модели и сохраняются в браузере. Файл другой модели, повреждённые данные и неизвестная версия формата отклоняются без изменения точек. Можно восстановить и пустой список.
- В **Редакторе точек** перетаскивайте строки списка **Порядок экскурсии** на нужное место. Кнопки **↑ / ↓** позволяют менять порядок с телефона или клавиатуры. Нажатие названия открывает редактирование. Порядок сохраняется автоматически и включается в экспорт.
- Нажмите **Начать экскурсию**: камера плавно перелетает к первой точке. На каждой остановке показываются название и описание; **Дальше** и **Назад** плавно перемещают камеру между точками в заданном порядке. На время перелёта управление отключается; после остановки можно свободно вращать вид вокруг точки и менять масштаб. **Выйти**, Escape или **Завершить** возвращают общий вид. Смена модели также завершает экскурсию.
- При включённом системном уменьшении анимации камера переходит к точкам без перелёта.

## Модели и лицензии

- **Витрина 1** — модель команды из файла [Витрина_compressed.glb](https://drive.google.com/file/d/1riLhZ1eA8yAqzuV2hqfCZKpQ4hihh99E/view), открывается первой.
