# Object Notes

Интерактивная галерея 3D-моделей на Three.js. Модель можно вращать, масштабировать, переключать через список и приближать к отмеченным деталям кликом по аннотации.

## Локальный запуск

Проект не требует сборки. В корне репозитория запустите `python -m http.server 8080`, затем откройте `http://localhost:8080`.

## Аннотации и экскурсия

- Нажмите **Редактор точек**, затем кликните по поверхности модели. Введите название и описание и нажмите **Сохранить**. Вращение модели перетаскиванием не добавляет точку.
- В редакторе нажмите на существующую точку, чтобы изменить текст или удалить её. Редактирование также доступно из карточки точки в обычном режиме.
- Точки и ракурсы новых точек сохраняются автоматически в `localStorage` отдельно для каждой модели. После перезагрузки они восстанавливаются. Данные доступны только в том же браузере и на том же адресе сайта; очистка данных сайта удаляет их. Общего серверного хранилища нет.
- Нажмите **Начать экскурсию**: камера плавно перелетает к первой точке. На каждой остановке показываются название и описание; **Дальше** и **Назад** переключают точки в порядке добавления. **Выйти**, Escape или **Завершить** возвращают общий вид. Смена модели также завершает экскурсию.
- При включённом системном уменьшении анимации камера переходит к точкам без перелёта.
